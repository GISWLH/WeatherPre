# 🌦️ WeatherPre

**一行预报，一行对比。**<br>
天气尺度（≤ 15 天）与次季节–季节尺度（S2S，> 15 天）预报：28 个 AI / 数值模式（GraphCast、AIFS、Aurora、FourCastNet 3、GEFS、ECMWF 延伸期、CFSv2 …）+ 2 个基准，统一用 WeatherBench-X 对 ERA5 评分。

```python
import weatherpre as wp

ds  = wp.forecast("graphcast", "z500", "7d", init="2020-10-03")            # 模型、变量、预报期 -> xarray
cmp = wp.compare(["graphcast", "pangu", "gefs", "ifs"], "z500,t2m", "7d", init="2020-10-03")
cmp.ranking()                                                               # 对 ERA5 评分并排名
```

## ✨ 特点

* **输入 模型 × 变量 × 预报期，直接得到结果**：不用处理 GRIB、插值或各家 API，所有模型输出同名同单位的 `xarray.Dataset`。
* **两种尺度，一个接口**：`"48h"`、`"7d"`、`"15d"` → **天气尺度**（逐预报时效场）；`"6w"`、`"45d"`、`"week3-4"` → **S2S 尺度**（周平均与距平）。
* **内置精度对比**：`wp.compare(...)` 把所有模型放到同一网格，用 [WeatherBench-X](https://github.com/google-research/weatherbenchX) 计算面积加权 RMSE 与 ACC（过去用 ERA5，最近的循环用 IFS 分析场代替），可对多个起报时刻平均、自动排名和出图。
* **13 个模型 + 2 个基准无需 GPU**：直接读取 WeatherBench 2、ECMWF Open Data、NOAA 开放数据桶中的现成预报。GPU 模型（AIFS v2、Aurora 1.5、FourCastNet 3、Atlas、U-CAST、WeatherNext 2、FuXi-S2S …）通过 [NVIDIA Earth2Studio](https://github.com/NVIDIA/earth2studio) 或 HF ZeroGPU，**调用方式完全相同**。
* **不重复造轮子**：每条路线都封装官方产品或上游库。

## ⚡ 快速开始

```python
# 天气尺度（≤ 15 天）
ds = wp.forecast("aifs", "t2m", "15d")                                   # 最新一轮 ECMWF AIFS，0.25°
ds = wp.forecast("gefs", ["z500", "tp"], "48h", init="2020-10-03")       # NOAA GEFS 集合平均
ds = wp.forecast("e2s:FCN3", "t2m", "7d", init="2020-10-03")             # 任意 Earth2Studio 模型（GPU）

# S2S 尺度（> 15 天）：周平均，第 k 周 = 起报后第 7(k-1)..7k 天
s = wp.forecast("ifs-ext", "t2m", "6w", init="2020-10-01")               # ECMWF 延伸期，第 1–6 周
s = wp.forecast("cfsv2", "tp", "week3-4")                                # 最新 CFSv2，第 3–4 周
wp.anomaly(s)                                                            # 相对 ERA5 1990–2017 周气候态的距平

# 精度对比（可对多个起报时刻平均）
cmp = wp.compare(["ifs-ext", "gefs", "cfsv2", "persistence", "climatology"], "t2m", "6w",
                 init="2020-10-01..2020-10-29")
cmp.table("acc"); cmp.ranking(); cmp.plot("scores.png"); cmp.plot_maps("week3.png", "t2m", 3)
```

```bash
weatherpre models --scale s2s
weatherpre forecast graphcast z500 7d --init 2020-10-03 --plot
weatherpre compare ifs-ext,gefs,cfsv2,climatology t2m 6w --init 2020-10-01
```

变量：`z500` [m]、`t850` [K]、`t2m` [K]、`msl` [hPa]、`tp` [mm，自起报累计；S2S 为 mm/day]。

## ⚠️ 局限

* 各存档覆盖不同：WeatherBench 2 预报为 1.5°、多为 2018–2022；ECMWF Open Data 仅保留约 4 天；GEFSv12 自 2020-09-23 起、00Z 可到 35 天；CFSv2（成员 1）未做偏差订正，S2S 距平含模式气候漂移（如高原地区）。
* 其他原生网格的模型先平滑到 WB2 1.5° 网格再评分，模型间公平，但与 WB2 的守恒插值不完全相同。
* GPU 路线已用 Earth2Studio 的 `Persistence` 模型在 CPU 上端到端测试；大模型需要 CUDA GPU，部分权重为非商用许可。
