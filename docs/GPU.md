# GPU routes / GPU 路线

* **HF Space (used, tested)** `LonghaoWang/weatherai-graphcast-smoke` → "WeatherPre" accordion (`hf/weatherpre_space.py`). API: `gradio_client.Client(space, token=$HF_TOKEN).predict(init, "era5"|"ifs", "24,48,...", "small"|"pretrained"|"finetuned", restart, api_name="/weatherpre_aurora")` (leads in hours, multiples of 6). One call = one chunk of 8 six-hour steps (~50–70 s of GPU, peak ~24 GiB); the rollout state is kept in `/tmp` on the Space and the reply starts with `MORE` or `OK`, so the client (`weatherpre/adapters/hf_space.py`) loops with `restart=False` until `OK` (a ZeroGPU proxy token only lives for one request; an aborted chunk is retried). A 15-day Aurora run is ~8 calls and is subject to the account's ZeroGPU quota (it paused between chunks when the quota was low). The checkpoint is fetched on CPU outside the GPU window. Space runs Python 3.10 → Earth2Studio (needs ≥3.11) is not installable there; only upstream packages that support 3.10 (microsoft-aurora, …).
* **Colab (written, not executed)** `notebooks/colab_aurora.ipynb` (same module as the HF run), `notebooks/colab_earth2studio.ipynb` (Earth2Studio models; API as documented upstream, wrapper `weatherpre/adapters/earth2studio_run.py` untested).
* **Box** CPU only (15 GB RAM): Aurora-small at 0.25° was OOM-killed on CPU, so inference stays on HF/Colab.
* **Earth2Studio (any CUDA box / Colab, tested on CPU with `Persistence`)** `weatherpre/adapters/earth2studio_run.py`: `wp.forecast("fcn3", "t2m", "7d", init=...)` or `wp.forecast("e2s:<ClassName>", ...)` loads `earth2studio.models.px.<ClassName>` with its default package, picks the initial conditions (ARCO ERA5 for past dates, GFS for the latest cycle, IFS for the AIFS family; override with `source=`), runs the upstream `earth2studio.run.deterministic` loop and converts the output to the WeatherPre schema (S2S leads are averaged into weekly means). Without a GPU it raises `BackendUnavailable` (set `WEATHERPRE_E2S_CPU=1` to force CPU). Catalog entries with an Earth2Studio class (checked against earth2studio 0.19/0.20): AIFS v2, AIFS-ENS v2, Aurora / Aurora 1.5, FourCastNet 3, SFNO, Atlas, U-CAST, WeatherNext 2 (Cyclones), GenCast-mini, FengWu, GraphCast operational, Pangu, FuXi, FuXi-S2S, DLESyM, ACE2.
